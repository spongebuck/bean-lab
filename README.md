# 豆点 · 拼豆图纸生成器

直接用浏览器打开 `index.html`，选择一张图片，就能生成拼豆参考图。

你可以：

- 选择小、中、大图纸（最长边分别为 30、50、80 格）作为快捷建议，或直接输入宽高（最大 500 格）；
- 图片默认完整显示，并自动留出安全边距。若自定义画板比例和原图不同，剩余区域会留作白色拼豆背景，而不会裁掉图片；
- 自动估算常见 29 × 29 格拼豆板的数量；
- 打印大图纸时，会自动按 25 × 25 格分页，并在每一页保留颜色编号与行列范围。
- 调整保留的颜色数量（4–36 色）；
- 显示或隐藏网格线、颜色编号；
- 查看每种颜色所需的拼豆数量；
- 下载 PNG 图纸或直接打印。

所有图片处理都在你的浏览器本地完成，不会上传到任何服务器。
