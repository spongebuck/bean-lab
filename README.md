# Saul's Bean Lab · 拼豆图纸生成器

直接用浏览器打开 `index.html`（或者部署到任何静态托管，比如 GitHub Pages），选一张图片，就能得到一份可以照着拼的拼豆图纸。

> 直接打开本地文件时，浏览器不允许读取文件夹里的图片，所以 Marvel 这类图片素材只能在网站上，或者在项目文件夹里运行 `python3 -m http.server` 之后打开。自己上传的图片和 Clawd 不受影响。

所有图片处理都在浏览器本地完成，不会上传到任何服务器。

## 能做什么

- **现成图纸**：首页按「套」收着，点开一套再挑：
  - **Clawd**：16 张 Claude Code 吉祥物的像素表情（经典、你好、写代码、思考中、摸鱼、吃瓜……）。每张都放得进一块 29 × 29 的板子，点开就是逐格对应的图纸，也可以存成 PNG 当表情包。
  - **Marvel**：25 个漫威电影标题，从《X战警》到《复仇者联盟5：毁灭之日》。点开按建议宽度（3–4 块板）生成，也可以改成任意尺寸。
  - 每一套都有自己的链接，比如 `…/#clawd`，可以直接分享。
- **真实色号**：默认匹配 MARD 221 色，也可以选 Perler、Hama Midi、Artkal S，或者不对应品牌的「自由配色」。材料清单上的色号和数量就是购物清单。
- **颜色数量**：设一个上限（2–48 色）。超出时，每次去掉「合并后误差最小」的那种颜色，所以眼睛、描边这类面积小但很关键的颜色会被留下。
- **干净的边缘**：每格取覆盖面积最大的颜色而不是平均色，描边和色块之间不会长出一圈过渡色；同一块纯色里的轻微噪点也不会被拆成两种豆子。
- **尺寸**：预设按整块拼豆板算（默认 29 × 29 格一块）：1 块、2 × 2、3 × 3。也可以直接输入宽高（5–500 格），可锁定原图比例，选择「完整显示」或「裁切填满」。
- **清理**：去除与边缘相连的纯色背景（比如白底），清理孤立的单颗杂点；亮度 / 对比度 / 饱和度微调。透明背景的图片自动留空。
- **预览**：拖动平移，⌘ / Ctrl + 滚轮或双指缩放，双击放大；顶部和左侧有固定标尺，每 5 / 10 格加粗，虚线标出拼豆板分界。鼠标悬停显示行列和色号，点格子或清单里的颜色只突出这一种。「效果」视图看拼好的样子。
- **进度**：拼完一种颜色就在清单里勾掉，图纸上对应的格子变淡，进度条跟着走。
- **导出**：
  - 下载 PNG：整张图纸，带坐标和材料图例；
  - 按板分页打印：封面是总览和材料清单，之后每块板一页。用 5 mm 豆时按 1:1 实物尺寸排版（打印时选「实际大小 / 100%」），可以垫在透明拼豆板下面照着放；
  - 复制材料清单（纯文本）。
- 支持拖入或粘贴（⌘V）图片；设置会记在本机浏览器里。
- 快捷键：`+` / `-` 缩放，`0` 适应窗口，`Esc` 取消高亮。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式（字体和配色沿用 imsaul.lol） |
| `app.js` | 全部逻辑：取色、配色、预览、导出、打印 |
| `palettes.js` | 拼豆品牌色卡数据 |
| `presets.js` | 现成图纸的目录：每一套的名字、说明和条目。Clawd 是几行字母，一个字母一格，直接改字母就能改图 |
| `presets/marvel/` | Marvel 电影标题图（已裁掉留白、缩小到最长 400 px） |
| `stickers/` | Clawd 表情包 PNG（透明背景，每格 24 px） |
| `favicon.svg` | 图标 |

## 关于 Clawd

Clawd 是 Anthropic 为 Claude Code 设计的吉祥物，这里的像素版是爱好者自己画的，非官方。身体用的是 Claude 橙 `#d97757`，在 MARD 色卡里对应 F23；其余颜色都直接取自 MARD 色卡，所以图纸和画出来的样子一一对应。

## 关于 Marvel 标题

电影标题字样归 Marvel Studios / Disney 所有，这里只供个人手作参考。要加一套新的图片素材，把图放进 `presets/<套名>/`，再在 `presets.js` 里照着 Marvel 那一段加一条就行。

## 色卡数据

色卡来自 [maxcleme/beadcolors](https://github.com/maxcleme/beadcolors)（MIT License）。透明、夜光、闪粉、珠光、荧光和金属色的豆子没有收录：它们的 RGB 值说明不了熨烫后的样子，自动匹配过去会误导。

这些色值是社区测量的近似值，不同批次、不同屏幕都会有偏差，买豆前最好对照实物色卡确认。
